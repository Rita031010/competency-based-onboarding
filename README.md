# competency-based-onboarding
Prototype for competency-based onboarding using employee skill gap analysis

This is a small HR analytics prototype that compares current employee skills with required role skills and identifies skill gaps.

## Purpose

The idea is to show how recruitment, competence, and learning data can support:

- skill gap analysis
- workforce planning
- internal upskilling
- learning and development decisions

## How it works

The prototype uses two example Excel files:

1. Current employee skills
2. Required skills for a target role

The script compares both files and produces a table showing missing or weaker skills.
