# competency-based-onboarding
Prototype for competency-based onboarding using employee skill gap analysis

This HR analytics prototype compares employee skills with role requirements, identifies skill gaps, and recommends onboarding and development actions.

## Purpose

The prototype demonstrates how recruitment data, such as CVs and interview scores, can be used to support competency-based onboarding.

## How it works

The prototype uses two example Excel files:

1. Current candidate skills
2. Required skills for a target role

The script compares both files and produces a table showing missing or weaker skills.

## Business value

This prototype helps managers and HR focus onboarding on areas where additional support may be needed.
